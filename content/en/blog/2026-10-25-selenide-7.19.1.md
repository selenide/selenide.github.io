### Birthday present: Java 11 support {#java-11}

As a birthday present, Selenide 7.19.1 is compiled for Java 11.

Yes, yes, we know. It's 2026. But there are still some unlucky dinosaurs out there who run their tests on Java 11.
This one is for you, dinosaurs! 🦖

But it's a one-time gift: birthdays don't happen every day. The next versions will require Java 17 again.
So please upgrade your Java. Seriously.

### Setting `Configuration.timezone` {#timezone}

In [Selenide 7.19.0](/2026/10/10/selenide-7.19.0/#mock-clock) we added method `clock().setTimezone()`.
But it changes the timezone only in the current tab.

Now there is a setting that sets the timezone for the whole browser — all tabs, windows and workers:

```java
Configuration.timezone = "America/New_York";
// or -Dselenide.timezone=America/New_York
```

How it works:
* A local Chrome, Edge or Firefox is started with environment variable `TZ`
  (browsers on Windows ignore it, so on Windows Selenide just logs a warning).
* A remote browser gets capability `se:timeZone` (supported by Selenium Grid in Docker).
* If you use capabilities `selenoid:options` or `moon:options`, `timeZone` is added to them as well.
* Only tz database IDs (like `Europe/Tallinn`) are accepted. An invalid timezone fails fast.

See [issue 3475](https://github.com/selenide/selenide/issues/3475) and [PR 3476](https://github.com/selenide/selenide/pull/3476).

<br>

### Option `--timezone` in Selenide CLI and MCP {#cli-mcp-timezone}

The same setting is now available in [Selenide CLI](/2026/08/20/selenide-7.18.0/#selenide-cli)
and [Selenide MCP server](/2026/04/10/selenide-7.16.0/#selenide-mcp-server):

```shell
selenide open --timezone=Asia/Tokyo https://selenide.org
```

See [issue 3475](https://github.com/selenide/selenide/issues/3475) and [PR 3476](https://github.com/selenide/selenide/pull/3476).

<br>

### Selenide CLI skill: HTML page dumps {#cli-skill-html-dumps}

The Selenide CLI skill now documents HTML page dumps.
Now your AI agent will know that it shouldn't take a screenshot every single time and try to analyze it as an image.
Instead, the agent should realize that it's more cost-effective to analyze the "*.html" file.

See [PR 3481](https://github.com/selenide/selenide/pull/3481).

<br>

### Clean up memory in `SelenideLogger` {#selenide-logger-leak}

When the last listener of a thread was removed, `SelenideLogger` still kept an empty entry for that thread.
With many threads, these entries could pile up. Now the thread's entry is removed when its last listener is removed.

Thanks to [Matthias Kurz](https://github.com/mkurz) for [PR 3463](https://github.com/selenide/selenide/pull/3463)!
